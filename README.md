# Gravity Digital

Sitio institucional de Gravity Digital, un microemprendimiento de asesoramiento informático, soporte remoto, capacitación personalizada y automatización de tareas para personas y PyMEs.

## Stack

- Next.js (App Router) y React
- TypeScript
- CSS responsivo con una interfaz oscura monocromática
- Lucide para iconografía

## Desarrollo local

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).

## Verificaciones

```bash
npm run typecheck
npm run build
```

El explorador de servicios presenta modalidades ilustrativas; no está conectado a un sistema de gestión ni publica precios fijos.
